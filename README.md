# calcservice-python

A lightweight calculator service with a simple command-line interface. It includes basic arithmetic, scientific math, programmer utilities, financial calculations, and a small engineering toolkit.

## Features

- Basic arithmetic expressions
- Scientific functions such as `sin`, `cos`, `sqrt`, `log`, and `factorial`
- Programmer mode for bitwise calculations and base conversions
- Financial calculator for simple/compound interest and loan payments
- Engineering helper calculations for power, force, Ohm's law, and more

## Usage

Run the CLI from the project root:

```bash
python main.py
```

Then select one of the available calculator modes.

## Example expressions

- `2 + 3 * 4`
- `sin(pi / 2)`
- `0xFF + 1`
- `0b1010 & 0b1100`

## Notes

- The calculator validates user input and rejects unsafe expressions.
- Use `exit` or `quit` to return to the main menu.
