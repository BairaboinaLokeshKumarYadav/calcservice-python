# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch. Older commits and branches may not receive security updates.

## Reporting a vulnerability

Please do not report a suspected vulnerability in a public issue or pull request.

If private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option on the repository's GitHub **Security** tab. Otherwise, contact the repository owner privately through GitHub and include **Security report** in the subject.

Include the affected version or commit, the relevant file or calculator mode, a concise description of the issue, and safe reproduction steps. Do not include real user data or secrets. Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure.

## Scope

The project is a local command-line calculator. Reports about unsafe expression handling, unexpected code execution, or dependency and release integrity are in scope. Do not use the calculator for sensitive data or as a security boundary.
