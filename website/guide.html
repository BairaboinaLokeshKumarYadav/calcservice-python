FIRST THINGS FIRST

Start calculating

Install Python 3.11 or newer. From the project directory, launch the command-line app:

python main.py

Choose a calculator from the menu and enter your values. At an expression prompt, type exit or quit to return. Choose option 6 to close the app.

QUICK FIXES

Troubleshooting

Why was my expression rejected?

Check the parentheses, operator spelling, and whether the selected mode supports that function. Expressions allow only a limited set of names and syntax; this is not a general Python interpreter.

Why is my trigonometric answer unexpected?

Scientific mode uses radians. Convert degrees with radians(value); convert a result to degrees with degrees(value).

What is programmer mode's bit width?

It controls the width of the wrapped result. Signed mode displays the top bit as a two's-complement sign; unsigned mode shows the non-negative value.

Can I use results for professional decisions?

Financial outputs are estimates, and engineering helpers cover basic formulas only. Consult qualified professionals for consequential decisions and validated designs.
